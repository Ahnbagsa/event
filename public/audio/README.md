# 공용 음원 넣는 방법

여기에 넣은 음원은 **앱을 여는 모든 사람이** 설정 → 음원 서랍에서 골라 쓸 수 있습니다.
맹세문·애국가·묵념곡처럼 학교마다 같은 것을 여기에 둡니다.
교가는 학교마다 다르므로 넣지 않습니다 — 각자 직접 올립니다.

## 두 걸음

### 1. mp3 파일을 이 폴더에 올린다

파일 이름은 **영문·숫자·붙임표만** 씁니다. 한글이나 띄어쓰기, 괄호, 물결표는 주소에서 깨질 수 있습니다.

지금 들어 있는 파일은 `원본번호-역할-구분.mp3` 꼴입니다. 앞의 번호는 원본 음원집의
번호를 그대로 남긴 것이라, 원본과 대조할 때 편합니다.

```
public/audio/17-2-anthem-verse1.mp3
```

### 2. `library.json`에 한 줄 더한다

```json
{
  "version": 1,
  "tracks": [
    {
      "id": "17-2-anthem-verse1",
      "role": "anthem",
      "label": "1절",
      "file": "17-2-anthem-verse1.mp3",
      "note": "가장 많이 쓰는 판본입니다",
      "durationSec": 69
    }
  ]
}
```

`label`은 **역할 이름을 빼고 판본만** 적습니다. 화면에 "이미 준비된 **애국가** 중에서 고르기"처럼
역할 이름이 이미 붙기 때문에, 여기에 또 "애국가"를 적으면 겹칩니다.

`main`에 올리면 배포가 자동으로 돌고, 앱에 그 음원이 나타납니다. **앱 코드는 고치지 않습니다.**

## 칸의 뜻

| 칸 | 꼭 필요한가 | 뜻 |
|---|---|---|
| `id` | 필요 | 다른 것과 겹치지 않는 이름. 파일 이름과 같게 두면 편합니다 |
| `role` | 필요 | 어느 자리에 쓸 음원인지. 아래 표에서 고릅니다 |
| `label` | 필요 | 화면에 보일 이름. 판본을 구별할 수 있게 적습니다 |
| `file` | 필요 | 이 폴더 안의 파일 이름 |
| `note` |  | 짧은 설명 |
| `credit` |  | 어디서 받은 음원인지 |
| `durationSec` |  | 대략의 길이(초). 목록에 보여 주기만 합니다 |

### `role`에 쓸 수 있는 값

| 값 | 자리 |
|---|---|
| `pledge` | 국기에 대한 맹세 |
| `anthem` | 애국가 |
| `silence` | 묵념곡 |
| `entrance` | 입장곡 |
| `exit` | 퇴장곡 |
| `award` | 시상 배경음 |

`schoolSong`(교가)은 학교마다 다르므로 여기에 넣지 않습니다.

## 판본이 여럿일 때

같은 `role`에 여러 줄을 넣으면 됩니다. 앱이 알아서 **고르는 목록**을 만듭니다.

```json
{ "id": "anthem-band-1", "role": "anthem", "label": "애국가 1절 (관악 반주)", "file": "anthem-band-1.mp3" },
{ "id": "anthem-choir",  "role": "anthem", "label": "애국가 (합창)",        "file": "anthem-choir.mp3" }
```

## 지금 들어 있는 것

| 역할 | 판본 | 개수 |
|---|---|---|
| `pledge` 국기에 대한 경례 | 일반 6종(맹세문 없음·성인 남/여·어린이 남/여/남녀) + 무전주 애국가 | 7 |
| `pledge` | 위와 같은 구성의 **국악** 판본 | 7 |
| `anthem` 애국가 | 1절 · 1~4절 · 국악 1절 · 국악 1~4절 | 4 |
| `silence` 묵념곡 | 일반 · 국악 | 2 |

교가(`schoolSong`)는 학교마다 다르므로 각자 **설정 → 음원 서랍**에서 직접 올립니다.

`src/media/libraryFile.test.ts`가 이 목록을 검사합니다. 적어 둔 줄이 하나라도 버려지거나,
가리키는 파일이 없거나, 올려만 두고 목록에 안 적은 mp3가 있으면 **테스트가 실패해 배포가 멈춥니다.**

## 지켜야 할 것

- **저작권.** 이 폴더의 파일은 누구나 받을 수 있게 공개됩니다.
  지금 들어 있는 20곡은 모두 **행정안전부가 제공하는 의식행사 음원**입니다.
  **특정 음반의 녹음은 안 됩니다.** 출처가 분명한 것만 올리고 `credit`에 어디서 받았는지
  적어 주세요. 비워 두면 테스트가 실패합니다.
- **동영상은 여기 넣지 않습니다.** 애국가 영상 1분이 10~30MB라 저장소가 금방 무거워지고,
  GitHub는 파일 하나에 100MB 한도가 있습니다. 영상은 각자 설정 → 음원 서랍에서 직접 올립니다.
- **줄 하나가 잘못돼도 나머지는 나옵니다.** 앱은 이 파일을 관대하게 읽습니다.
  그래서 오타가 나면 오류 대신 **그 음원만 조용히 안 보입니다.** 안 보이면 철자부터 확인하세요.
- 이 파일이 아예 없거나 비어 있어도 앱은 그대로 동작합니다. 고르기 칸만 접힙니다.
